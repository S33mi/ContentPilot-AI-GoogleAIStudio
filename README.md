# ContentPilot AI

**AI-powered content generation agent for local small businesses and freelancers.**

ContentPilot helps small businesses create professional social media posts, product descriptions, and customer replies in seconds using **Google Gemini**.

🌐 **Live Demo**: [https://contentpilot-ai.ai.studio](https://contentpilot-ai.ai.studio)

---

## Features

- **7-Day Social Media Content Pack** (Instagram, Facebook, X, LinkedIn)
- **Product / Service Descriptions**
- **Customer Reply Suggestions** (Reviews, Inquiries, Complaints, Compliments)
- **Multi-language Support** (English, Urdu, Arabic, Persian, Turkish, and more)
- **Export Options**: PDF, Word, Excel, CSV, JSON
- **Google Login** + Freemium model
- **Cloud Library** for paid users
- **Paddle Payments** (Monthly & Yearly plans)

---

## Tech Stack

- **AI**: Google Gemini API
- **Frontend**: React + Vite (Google AI Studio)
- **Authentication**: Firebase Authentication
- **Database**: Cloud Firestore
- **Payments**: Paddle (Merchant of Record)
- **Hosting**: Google Cloud (Cloud Run)

---

## How AI is Used (AI-Native Operations)

ContentPilot is built around Google Gemini as the core engine:

1. User enters business details (name, type, location, description, audience, tone, working hours)
2. Carefully engineered prompts are sent to Gemini
3. Gemini generates high-quality, personalized marketing content
4. All generation happens live in production via the Gemini API

The core value of the product is delivered by AI.
